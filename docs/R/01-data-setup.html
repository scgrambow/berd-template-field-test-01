2.1 Overview

This document introduces the IVAM-ED synthetic dataset and walks through the first analytical step in any research project: understanding your data before analyzing it.

By the end of this module you should be able to:

  1. Load a dataset in R and inspect its structure.
  2. Identify variable types (continuous, binary, ordinal) and their scales.
  3. Count missing values and understand why they occur.
  4. Recognize the difference between baseline measurements and follow-up measurements.

2.2 The IVAM-ED Study

The IVAM-ED trial evaluated whether a voice-activated smart speaker (Amazon Echo Dot) could improve mental health and diabetes self-management among older adults with type 2 diabetes. Researchers in Brazil randomly assigned 112 adults (age ≥ 65) to either:

  • Intervention: Use a smart speaker at home for 12 weeks. The device was programmed with reminders, health messages, and educational podcasts.
  • Usual care: Continue with standard diabetes management and no device.

The primary outcome was the SRQ-20 score (Self-Reporting Questionnaire, 0–20), a measure of mental distress. Lower scores mean less distress.

Important: We are working with a synthetic (simulated) dataset — not real participant data. The dataset was constructed to approximate the published summary statistics. See simulation-assumptions.md for how it was built and what assumptions were made.

Note

Why the data are always the same: set.seed()

At the top of simulate-ivam-ed.R you will find set.seed(241). This locks R’s random number generator to a fixed starting point. R’s “randomness” is actually a deterministic algorithm — a mathematical formula that produces a long sequence of numbers that look random but are completely determined by the starting value (the seed). Given the same seed, R will always generate the same sequence.

This is deliberate for a teaching dataset: every student gets identical data, so results are comparable and answers are verifiable.

Try it yourself: Open R/simulate-ivam-ed.R, change set.seed(241) to set.seed(999), source the script, and re-run this module. Your Table 1 means will shift slightly, the primary ANCOVA result may change in magnitude, and it may or may not remain statistically significant — illustrating that any single study is one realization of a random process.

Tip

Score directions to keep in mind:

  • SRQ-20 (0–20): Higher score = MORE mental distress (bad)
  • SF-36 (0–100): Higher score = BETTER quality of life (good)

  • SCI-R (0–56): Higher = BETTER self-care adherence (good)
  • PSS (0–40): Higher = MORE perceived stress (bad)

2.8 5. Missing Data

Not everyone completed the 12-week follow-up. In the real trial, 9 participants (8%) did not return for the follow-up visit — 3 died and 6 were lost to follow-up.

2.9 6. Quick Sanity Checks

Before doing any analysis, it is good practice to check for values that fall outside the expected instrument ranges. These could indicate data entry errors (in real data) or simulation bugs (in synthetic data).

# Check that all scores fall within their valid ranges
# Any TRUE in the "out_of_range" column would indicate a problem

range_checks <- tibble(
  variable  = c("srq20_0",  "srq20_12", "sf36_0",  "sf36_12",
                "sci_r_0", "sci_r_12", "pss_0",   "pss_12",
                "hba1c_0", "hba1c_12", "mmse_0"),
  min_valid = c(0,  0,  0,   0,  0, 0, 0,  0,  4.5, 4.5, 0),
  max_valid = c(20, 20, 100, 100, 56, 56, 40, 40, 18,  18,  30)
)

range_checks |>
  rowwise() |>
  mutate(
    obs_min = min(dat[[variable]], na.rm = TRUE),
    obs_max = max(dat[[variable]], na.rm = TRUE),
    out_of_range = obs_min < min_valid | obs_max > max_valid
  )

2.10 7. Save a Clean Working Copy

It is good practice to keep the raw data unchanged and save a separate working copy with any modifications (like renaming variables or recoding groups).

# Create a working copy with a descriptive group label
dat_work <- dat |>
  mutate(
    group_label = factor(group,
                         levels = c(0, 1),
                         labels = c("Usual care", "Smart speaker"))
  )

# Save the working copy
saveRDS(dat_work, file = "../data/ivam_working.rds")

cat("Working dataset saved to data/ivam_working.rds\n")
