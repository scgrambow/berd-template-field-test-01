3.1 Overview

This module covers the first analytical step after loading your data: describing the sample. In a randomized trial, descriptive statistics serve two purposes:

  1. Characterize who was in the study — so readers know whether the findings might apply to other populations.
  2. Check that randomization worked — by comparing baseline characteristics between the intervention and control groups.

By the end of this module you should be able to:

  1. Compute means, standard deviations, medians, and frequencies for continuous and categorical variables.
  2. Construct a formatted baseline characteristics table (Table 1).
  3. Explain why we do not perform significance tests of baseline differences in a randomized trial.
  4. Distinguish between clinically meaningful and trivially small group differences at baseline.

3.5 1. Univariate Summaries

Before building a grouped table, it helps to look at the whole sample together. This gives you a feel for the data and catches obvious problems (values out of range, unexpected distributions).

3.5.1 Continuous variables

# Summarize all continuous outcome and clinical variables
dat |>
  select(age, edu_years, income_wages, dm_duration_y,
         mmse_0, srq20_0, sci_r_0, pss_0, sf36_0, hba1c_0) |>
  summarise(across(everything(),
    list(
      n     = \(x) sum(!is.na(x)),
      mean  = \(x) round(mean(x, na.rm = TRUE), 1),
      sd    = \(x) round(sd(x,   na.rm = TRUE), 1),
      min   = \(x) round(min(x,  na.rm = TRUE), 1),
      max   = \(x) round(max(x,  na.rm = TRUE), 1)
    ),
    .names = "{.col}__{.fn}"
  )) |>
  tidyr::pivot_longer(everything(),
    names_to  = c("variable", "stat"),
    names_sep = "__"
  ) |>
  tidyr::pivot_wider(names_from = stat, values_from = value)

Tip

What pivot_longer() and pivot_wider() do: R stores data in either wide or long format. Wide format has one row per participant with many columns. Long format has one row per observation, with a column identifying what variable that row describes.

We used pivot_longer() above to convert the summarise() output — which has one column per statistic — into a long table where each row is one (variable, statistic) pair. Then pivot_wider() re-shapes it so each statistic becomes its own column. This pattern appears throughout the modules whenever we need to reshape data for a cleaner table or a grouped plot.

Note

What to notice: Compare the means and SDs to the published Table 1 in Matzenbacher et al. (2026). The pooled (overall) values should be close. Small differences are expected because this is a simulation.

3.7 2. Table 1: Baseline Characteristics by Randomized Group

The standard way to present baseline characteristics in a clinical trial is a Table 1: one column per group, with each row showing a baseline variable.

We use gtsummary::tbl_summary() to build this table. The package automatically selects appropriate statistics (mean ± SD for continuous variables, n (%) for categorical variables) and formats the output for publication.

# Prepare a clean analysis dataset for Table 1
# Rename group to a labeled factor so the column headers read clearly
dat_t1 <- dat |>
  select(
    group_label,
    # Demographics
    age, female, edu_years, income_wages,
    # Clinical
    dm_duration_y, insulin,
    # Comorbidities
    hx_depression, hx_anxiety, cognitive_decline,
    # Baseline scores
    mmse_0, srq20_0, sci_r_0, pss_0, sf36_0, hba1c_0
  ) |>
  mutate(
    # Convert binary integers to labeled factors for cleaner table display
    female            = factor(female,            levels = c(1, 0), labels = c("Female", "Male")),
    insulin           = factor(insulin,           levels = c(1, 0), labels = c("Yes", "No")),
    hx_depression     = factor(hx_depression,     levels = c(1, 0), labels = c("Yes", "No")),
    hx_anxiety        = factor(hx_anxiety,        levels = c(1, 0), labels = c("Yes", "No")),
    cognitive_decline = factor(cognitive_decline, levels = c(1, 0), labels = c("Yes", "No"))
  )

3.9 3. Interpreting Baseline Balance

3.9.1 3a. What “balanced” means in a randomized trial

After randomization, we compare baseline characteristics between groups. In a perfectly balanced trial, every characteristic would be identical across groups. In practice, small differences always occur by chance, even with proper randomization.

The key question is: are any of the differences large enough to matter?

# Calculate the mean difference between groups for each continuous outcome
# and the standardized mean difference (SMD)
dat |>
  group_by(group_label) |>
  summarise(
    age_mean       = mean(age),
    srq20_mean     = mean(srq20_0),
    hba1c_mean     = mean(hba1c_0),
    sf36_mean      = mean(sf36_0),
    pss_mean       = mean(pss_0),
    sci_r_mean     = mean(sci_r_0)
  ) |>
  tidyr::pivot_longer(-group_label, names_to = "variable", values_to = "mean") |>
  tidyr::pivot_wider(names_from = group_label, values_from = mean) |>
  mutate(difference = round(`Smart speaker` - `Usual care`, 2))

3.9.2 3b. Why we do NOT test for statistical significance at baseline

You may notice that Table 1 in our simulated output (and in most published trials) does not include a p-value column. This is intentional, and it is one of the most important conventions in clinical trial reporting.

The reason: In a properly randomized trial, any baseline difference between groups arose by chance — by definition, because we randomized. Testing whether a baseline difference is “statistically significant” asks: “Is this difference too large to be due to chance?” But we already know it is due to chance (the randomization). The test cannot tell us anything informative.

What matters instead is whether the difference is clinically meaningful — large enough to affect the outcome, regardless of its p-value. A large p-value does not mean a baseline imbalance is unimportant; it means only that the sample was too small to detect it with confidence.

Important

CONSORT reporting guideline: Table 1 in a randomized trial should show baseline characteristics but should not include p-values for between-group comparisons. This is stated explicitly in the CONSORT 2010 guidelines (Schulz et al., 2010, BMJ).

3.9.3 3c. Standardized mean differences

A more informative measure of baseline balance is the standardized mean difference (SMD): the group difference divided by the pooled standard deviation. Values below 0.1 are generally considered small (good balance); values above 0.2 may warrant adjustment in the primary analysis.

# gtsummary can add SMDs directly to the Table 1
tbl_summary(
  dat_t1 |> select(group_label, age, srq20_0, hba1c_0, sf36_0, pss_0, sci_r_0),
  by = group_label,
  statistic = list(all_continuous() ~ "{mean} ({sd})"),
  digits    = list(all_continuous() ~ 1),
  missing   = "no"
) |>
  add_difference(test = list(all_continuous() ~ "smd")) |>
  modify_header(estimate ~ "**SMD**") |>
  bold_labels()
