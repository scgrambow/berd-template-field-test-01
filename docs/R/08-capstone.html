9.1 Overview

The seven preceding modules have taught you to handle data, describe samples, visualize distributions, estimate effects, model with ANCOVA, handle missing data, and critically appraise findings. This capstone exercise asks you to bring those skills together in a single task that closely mirrors real research work:

Write a complete Methods and Results section for the primary outcome of the IVAM-ED trial, as if you were the corresponding author.

There is no new code to introduce. The challenge is synthesis — using what you have already computed to produce coherent, accurate, publication-ready prose.

9.2 Background: What a Methods and Results Section Looks Like

In a randomized clinical trial report, the Methods section describes what was done (design, participants, intervention, outcomes, analysis). The Results section describes what was found (flow of participants, baseline characteristics, primary outcome, secondary outcomes). Together they answer: “What did the investigators do, and what happened?”

The target length for this exercise is approximately 400–600 words total (Methods + Results). Brevity and precision are both required. Every number should match your analysis output. Every analytical choice should be described accurately.

9.4 Part 2: Write the Methods Section

Using the analysis output above and your knowledge of the study design, write a Methods section covering the following elements. Your prose should be accurate, concise, and written in the past tense.

Required elements:

  1. Study design: State the design (randomized clinical trial), setting, and enrollment period.
  2. Participants: State the key eligibility criteria (age ≥ 65, type 2 diabetes) and the enrolled sample size.
  3. Randomization: Describe how participants were assigned (1:1 ratio, computer- generated simple random sequence, no stratification or blocking).
  4. Intervention: Describe what the smart speaker group received and for how long. State that the control group received usual care.
  5. Primary outcome: Name the SRQ-20, state its range and directionality (higher = more distress), and state that it was assessed at 12 weeks.
  6. Statistical analysis: State that the primary analysis was a baseline-adjusted ANCOVA with group and baseline SRQ-20 as predictors. State the significance threshold (α = 0.05). Describe the BOCF sensitivity analysis.
  7. Missing data: State the number missing and the assumed mechanism (MAR).

9.5 Part 3: Write the Results Section

Using the numbers from your analysis output, write a Results section covering the following elements. Every number must match your output — not the published paper (you are reporting the synthetic dataset).

Required elements:

  1. Participant flow: State how many were enrolled, how many completed follow-up, and the reasons for dropout.
  2. Baseline characteristics: Summarize the groups briefly (one or two sentences comparing key variables). Do not say the groups were “significantly different” on baseline characteristics — state whether any differences are clinically notable.
  3. Primary outcome: Report the adjusted mean (SE) for each group at 12 weeks, the mean difference (95% CI), and the p-value from the baseline-adjusted ANCOVA. Then report the fully adjusted model result.
  4. Sensitivity analysis: State that the BOCF analysis produced a consistent finding.
  5. Interpretation sentence: Write one sentence interpreting what the result means clinically, including a comparison to the approximate MCID of 3 points.
